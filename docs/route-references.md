# 单层路由引用

## 使用方式

在「路由管理 → 路由规则」选择主入口，将候选类型切换为「路由入口引用」，选择目标入口并追加到队列。该项代表目标入口的完整候选组，而不是复制其内部站点规则。

例如：

```text
my-main
  1. 站点 A 的模型
  2. 引用 gpt-6.1-sol（由号池生成）
  3. 后备站点 E 的模型
```

客户端仍请求 `my-main`。满足现有回退条件时，执行顺序为 A → 目标入口当前可用候选 → E。引用内部的配额排序和会话亲和不能跨过父级队列中的其他组。流式输出已经提交、严格客户端错误或取消等停止条件继续沿用现有规则，不保证所有错误都遍历全部候选。

追加、移动、启停、移除后自动保存。时间规则有未确认草稿时，先确认或取消草稿，再进行其他队列操作。池托管入口可在路由页面对已有候选排序和启停，成员及暴露模型仍在「号池」管理；不支持在此追加、移除候选或修改时间规则。同步保留仍有效候选的设置，新成员追加。配额排序和会话亲和启用时，实际选路可能不同于手工顺序。

## 动态更新与身份

- 引用使用目标 `ProxyRouteEntry.Id`；模型名仅用于显示，不作为重连依据。
- 号池同步可能重建内部规则 ID，但保留的模型入口 ID 不变，因此成员变化无需重新保存引用方。
- 仅支持一层：被引用入口不能包含其他引用。自引用、循环、禁用引用造成的嵌套，以及把已被引用入口改为引用入口，均在保存时拒绝。
- 外层与内层的启用和时间条件同时生效。凭证、协议、请求头、兼容规则、思考参数与出口配置使用实际内部候选的既有配置，不叠加第二轮协议转换。
- 主路由访问权限允许执行其管理员配置的内部引用；不要求客户端同时获准直接访问目标入口。
- 实际站点/Key/模型共享熔断、冷却与并发状态；含引用的请求对等价转发目标进行请求内去重，不合并具有不同有效转发配置的候选。

## 删除与失效

- 删号池或从池的托管模型清单取消某模型时，会删除对应的、明确标记属于该池的规则；入口没有剩余规则时一并删除，仍有其他规则时则解除托管并保留入口和剩余规则（包括归属不明的旧规则，需人工检查清理）。
- 目标入口被删除时，其他入口中的引用项保留，显示目标失效，请求时跳过；父入口和其他候选不会被一起删除。入口解除托管而保留时，引用仍指向该入口。
- 同名目标后来重新创建会得到新 ID，旧引用不会自动接到新目标，需显式移除并重新选择。
- 手工删除被引用入口需要额外确认。确认后保留引用方的失效项，以便定位和修复。
- 已取得执行快照的在途请求保留原快照。配置保存的延迟发布会保护相关入口的完整旧计划；破坏性删除会清除面向后续请求的旧保护快照，避免继续使用已删候选。

## 兼容性与实现位置

历史站点规则保持旧排序和策略行为。数据库启动通过 CodeFirst 增列并补齐历史缺失入口，不重新分配已有入口 ID。旧客户端可继续维护纯站点入口，但不能用不识别引用的请求覆盖包含引用的配置。桌面端对含引用或号池托管入口仍只读，候选排序和启停使用 Web。

核心代码：
- `ProxyRouteRule`：目标类型与目标入口 ID。
- `RouteRulesApiController`：选择候选、图校验、事务保存及删除保护。
- `RouteGraphMutationGate`：低频图变更串行化。
- `ProxyRequestMetadataCache`：单层候选展开、独立快照与变更前依赖捕获。
- `RouteCandidatePolicyService`：含引用队列的组内配额/亲和排序。
- `RouteAttemptTracker`：等价尝试认领。
- `ModelConcurrencyLimiter`：准确槽位释放与延迟发布。

管理接口增量：
- `GET /api/admin/route-rules/reference-targets?parentEntryName=...` 返回可选入口及禁止选择原因。
- `POST /api/admin/route-rules/save` 新编辑器携带 `supportsRouteReferences: true`，规则用 `targetKind: Site | RouteEntry` 区分；引用携带 `targetRouteEntryId`。
- `POST /api/admin/route-rules/entries/delete` 对存在入站引用的入口默认拒绝；明确确认后携带 `confirmReferenced: true`。

验证必须使用隔离 SQLite、合成凭证与假上游；不要以真实号池的保存、同步、删除作为冒烟测试。

号池候选排序和启停通过 `POST /api/admin/route-rules/pool-queue` 原地更新，携带入口 ID、完整规则 ID 与读取时的排序/启用状态；队列被同步或其他编辑更改时返回 409，不覆盖新配置。编辑保留规则 ID、入口 ID 和时间规则，引用方随缓存发布更新。号池同步在成员持续符合条件时保留这些配置；成员被排除、模型不再提供或托管入口被移除时对应规则会删除，之后重新加入目前会按新规则生成，不保证恢复原设置。
