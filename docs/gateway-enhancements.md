# 网关增强

管理入口为「代理配置 → 网关增强」。配置通过 `/api/admin/gateway-enhancements` 读取和保存；凭据使用部署的 Data Protection 密钥保护，保存于 `gateway-enhancements.json`，需与密钥圈一起备份。默认关闭会改变请求行为的开关。

## 稳定性

- 流式保活：已写出内容的 SSE 在完整事件边界发送注释，不改变上游 usage，不在未知协议、WebSocket 或半个事件中注入内容。该版本不在首响应之前发送保活，也不能替代 Claude/Codex 自身的事件超时。
- 扩展首包缓冲：Responses/Chat 的热身缓冲最多 256 块或 64KB，仍受上游空闲超时约束；发生真正输出后放行。不是无限重试或透明续写。
- 循环检测：分别观察推理和正文的 256 句窗口，低于等于 24 种语句时中止。忽略工具参数、纯符号、数字代码行；不自动重试可能已执行工具的回答。
- 缓存亲和：现有会话亲和启用后使用五分钟成功活动窗口，过期重新参与已有额度排序；不放宽引用 owner 约束。

## 会话与流量

客户端通过 `Session-Id`、`Thread-Id`、`X-Session-Id` 或 `X-Conversation-Id` 提供稳定标识；子代理可额外提供 `X-Parent-Session-Id`。标识按访问密钥隔离并哈希，不存正文。请求日志新增摘要列，会话页展示输入、缓存、输出、当前价格估算、站点切换与字节。请求字节取 Content-Length，响应字节为应用写出字节，包含保活，不是 TLS/HTTP 压缩后的线路流量。WebSocket 记录每轮 JSON 字节，不包含帧或 TLS 开销。查询最多读取最近两万条尝试，避免管理查询耗尽内存。

`GatewayRequestMetrics` 保存接入账本，WebSocket 每轮结算并记录 JSON 消息字节。会话查询触发保留清理，至少保留 32 天以覆盖预算周期。价格缺失显示未定价，不解释为零费用。

## 预算

按访问密钥配置 UTC 日、周一开始的周、自然月 token 和美元预算；0 表示不限。预算键按单进程串行接入，避免并发请求全部读取旧值。实际 usage 在 HTTP 请求或 WebSocket 单轮结束时进入独立账本，因此包含多次候选尝试；正在执行的一次请求可能超过剩余额度。不是 token 预扣或跨进程原子限额。金额按调用时价格固化，遇到未定价用量会拒绝当前周期后续金额预算请求；补价格后等待新周期或改用 token 预算，旧账本不会自动重算。启用之前的历史用量不追溯。搜索与远程 MCP 服务自身费用不计入模型预算。

## 搜索、识图和 MCP

- `POST /v1/tools/search`：访问密钥认证，`{query}`，管理端配置支持 SearXNG JSON 的 HTTP 搜索服务；最多返回十条结果。
- `POST /v1/tools/describe-image`：`{imageUrl,query}`，通过配置的本机识图路由转发，内层代理执行原有授权、出口和 token 入账。支持 HTTPS 图片或图片 data URL。需要真实监听端口。
- `POST /mcp/aitool`：HTTP MCP 工具路由，支持 initialize、ping、tools/list、tools/call，配置相应服务时提供 `aitool_search`、`aitool_describe_image`。内置工具和远程服务分别配置允许的访问密钥。远程 MCP 名称前缀隔离，每次操作初始化独立上游会话。当前不支持 stdio、resources、prompts、订阅或服务端反向请求。管理配置的目标可指向内网，不接受匿名客户端提供目标地址。
- 搜索不是自动注入对话，识图不是透明替换图片；调用方须显式调用工具。搜索和远程 MCP 的供应商费用不作为模型 token 估算。

## 客户端配置

Codex、Claude Code 支持本机配置状态、预览、写入、原始文件备份和漂移检查；写入仅允许本机管理连接并校验当前文件哈希。Codex 使用 `AITOOL_API_KEY` 环境变量，不将密钥写入 TOML。Claude 的 env 配置包含访问密钥。服务主机与客户端不是同一台机器时用预览导出；WSL 目前导出后手动写入，不自动枚举或更改发行版。复杂 TOML 多行字符串拒绝自动改写。恢复会恢复整份接入前备份，因此发生外部修改时拒绝恢复。

## 验证

`GatewayEnhancementTests` 覆盖循环正文/工具参数区分、UTC 预算窗口、预算在转发前拒绝及会话哈希与原有 token 总数一致。原有代理集成测试用于验证关闭增强时既有路径保持可用。真实搜索、识图、MCP 及本机文件操作仍须使用实际服务配置验证。
